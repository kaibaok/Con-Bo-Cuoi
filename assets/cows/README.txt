Thư mục ảnh bò của bạn.

Bỏ ảnh vào đây theo tên sau, game tự dùng khi tải lại trang:

  normal.png          Bò thường, lúc bình thường
  normal-hooked.png   Bò thường, lúc bị bắt dây
  small / big / fast / mad / red / gold / rainbow / witch / ghost   làm tương tự

Đuôi tệp: png, webp hoặc jpg. Nên dùng PNG nền trong suốt.
Nếu chạy game bằng start-game.bat, ảnh chọn trong Cài đặt sẽ được lưu thẳng vào thư mục này.
